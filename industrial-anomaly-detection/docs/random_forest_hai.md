# Baseline Random Forest Classifier для HAI

Реализованы `src/models/baseline.py` и воспроизводимый запуск `python -m src.run_random_forest_hai`. Три модели уже обучены: seeds 42, 43, 44. Существующая версия не перезаписывается. Конфигурация зафиксирована в `configs/random_forest_hai.json`, копия протокола — в artifacts.

## Протокол

- Источники: весь raw train1 и первые 70% raw train2, с исходной attack-разметкой. Первые 30 строк каждого источника используются только как история. Окна между файлами не соединяются.
- Из 478380 допустимых train-целей сохранены все 776 атакующих и 100000 нормальных, выбранных только внутри train с seed 42. Один и тот же набор используется для трёх лесов. Выборка не изменяет исходные истории и не переносит записи между split.
- В отличие от Transformer v2, который обучался только на нормальных окнах, RF получает размеченные атаки. В train2 это лишь два размеченных атакующих интервала; полноценное покрытие типов атак не предполагается.
- Validation: следующие 15% train2. Calibration: последние 15% train2. Это те же временные интервалы, что у Transformer v2. Перебор гиперпараметров не выполнялся.
- Порог каждого seed — 99-й процентиль score на отдельной normal calibration; решение строго score > threshold. Из-за дискретных score и совпадающих значений FPR не обязан равняться ровно 1%.
- Test: те же 152970 цели test2, с побитово совпадающими timestamp и метками относительно сохранённой оценки Transformer. Warmup=30. Нет point adjustment.
- Test2 уже просмотрен на предыдущем этапе: сравнение ретроспективное и описательное. Он не объявляется новым слепым holdout; пороги по его метрикам не менялись.

## Признаки и модель

55 числовых каналов преобразуются сохранённым normal-train scaler v2 без refit. Четыре булевых канала остаются 0/1. Для каждого из 59 каналов формируются текущая величина, mean/std/min/max по 30 предыдущим наблюдениям и разность текущего/предыдущего значения: всего 354 признака.

Это компактное представление прошлого, а не flattened матрица всех 31 наблюдений. Будущие строки, время как feature и четыре столбца attack-разметки исключены из входов. Метка — attack текущей целевой строки. Текущее наблюдение доступно RF в момент решения; Transformer использует его для ошибки относительно прогноза из прошлого.

Параметры: 100 деревьев, max_depth=16, min_samples_leaf=2, max_features=sqrt, class_weight=balanced_subsample, n_jobs=4. Сохраняемый score — predict_proba класса Attack; после sampling/весов классов он не считается калиброванной вероятностью реальной атаки.

## Артефакты

`artifacts/hai/random_forest/hai_rf_classifier_v1/`:

- `protocol.json`, `training_manifest.json`, `training_targets.csv` — происхождение, целевые строки, sampling и порядок признаков.
- `preprocessing.joblib`, `preprocessing_manifest.json` — копия неизменённого scaler v2.
- `seed42/`, `seed43/`, `seed44/`: model.joblib, threshold.json, validation/calibration scores, feature_importances.csv.

`results/hai/random_forest/hai_rf_classifier_v1/`:

- comparison.csv — четыре строки: три RF seeds и существующий Transformer seed42.
- comparison_summary.csv — RF mean/std по трём seeds и Transformer seed42.
- comparison.png и report.md.
- seed*/metrics.json, test_predictions.csv, figures/ — отдельные оценки моделей.
- diagnostics.json — проверка распознавания обучающих атак без изменения модели/порога.

Joblib-модель восстанавливается без обучения; совпадение score после save/load проверено до открытия test для RF-scoring. Контрольные суммы связывают модель, threshold и preprocessing. Ни один RF seed не выбран как «лучший по test» — приведены все три.

## Проверки и границы вывода

Тесты проверяют известные значения временных признаков, независимость от будущего, запрет окон через разрывы, сохранение всех train-атак при sampling, воспроизводимость выборки, отказ обучения классификатора на одном классе и save/load score. Весь набор из 27 тестов проекта прошёл.

Высокая Accuracy при нулевом Recall не означает работоспособный детектор: класс Normal преобладает. Нулевой FPR может означать отсутствие любых предупреждений. Сравнение RF/Transformer здесь смешивает различия архитектуры, доступа к разметке, training sampling и представления истории; это раскрывается в отчёте и не используется как доказательство универсального превосходства одной архитектуры.

Установка и версии библиотек берутся из существующего requirements.txt. Для запуска из другого окружения сначала подготовить те же HAI-источники и preprocessing v2. Этот baseline не является экспериментом на SWaT или доказательством zero-day обобщения.
